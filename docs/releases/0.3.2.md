# Lavanda 0.3.2 — Atajos y Loupe opcional

Fecha: 2026-10-19. Etiqueta: lavanda-v0.3.2.

## Cambios acumulados desde 0.3.1

El componente opcional `shortcuts` queda así:

| Atajo | Acción |
| --- | --- |
| Super+C | Visual Studio Code; reemplaza copiar universal de Omarchy. |
| Super+Shift+C | Cuentagotas: seleccionar un color y copiar su valor. |
| Super+Shift+N | Omawrite; reemplaza el lanzamiento del editor predeterminado. |
| Super+Shift+W | WhatsApp, sin cambios. |
| Super+Shift+S | Captura de pantalla, sin cambios. |

Ctrl+C conserva su comportamiento habitual. El editor predeterminado no cambia.
El atajo existente Super+Print para el cuentagotas también se conserva.

Incluye además el componente opcional `loupe`, incorporado a main el 15/10:
asociaciones de imágenes y ventanas flotantes centradas. No instala Showtime ni
cambia asociaciones de vídeo. El portátil puede tener ya esta configuración;
compararla antes de proponer Loupe de nuevo.

## Actualización del portátil

Seguir AGENTS.md y docs/actualizaciones.md. Consultar estado y retornos primero.
Para recibir únicamente los atajos, mantener esta selección explícita:

```bash
./install.sh packages --only shortcuts
./install.sh doctor --only shortcuts
./install.sh plan --diff --only shortcuts
# Tras aprobar el plan:
./install.sh apply --only shortcuts
./install.sh doctor --only shortcuts
./install.sh plan --diff --only shortcuts
```

Dependencias: VS Code, Omawrite, Hyprland, hyprpicker, wl-copy y pkill.
`packages` ofrece hyprpicker y wl-clipboard si hacen falta; instalarlos solo
mediante el paso explícito de paquetes aprobado. Omawrite y VS Code deben estar
disponibles; doctor informa si faltan. No actualizar Omarchy como efecto colateral.

Revisar posibles overrides posteriores al bloque administrado SHORTCUTS que
reutilicen estas teclas. Preservar otros atajos y ajustes propios. No reaplicar
`editors`: sigue pendiente la detección de code.desktop frente a
com.microsoft.VSCode.desktop y el portátil tiene una adaptación local.

## Comprobaciones y recuperación

El instalador conserva una copia previa: guardar su identificador y recuperar
con `./install.sh restore ID` si fuera necesario. Después de apply o restore,
comprobar `hyprctl reload` y `hyprctl configerrors`.

En oficina se aplicaron los atajos a la configuración personal, Hyprland cargó
las asignaciones sin errores y Raúl aprobó el resultado. Esa edición local no
constituye una instalación completa de todos los componentes de esta versión.
Las 56 pruebas del instalador y la búsqueda de emojis pasan; sintaxis de
install.sh y diff comprobados. Las pruebas cubren aplicación, idempotencia y restauración en HOME
temporal, incluyendo los atajos nuevos y la conservación de datos privados.
En el portátil queda pendiente aplicar y validar los atajos con Raúl.

Las notas de 0.3.0 y 0.3.1 siguen siendo necesarias si se saltan versiones.
