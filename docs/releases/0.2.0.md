# Lavanda 0.2.0 — continuidad entre equipos

Fecha: 2026-09-28. Etiqueta: lavanda-v0.2.0.

## Desde la instalación original del portátil

- Compatibilidad explícita con las bases comprobadas de Omarchy 4.0.3 y 4.0.4;
  mínimo fzf 0.74.3. No se eliminan los controles de huellas.
- Dependencia ble.sh instalable explícitamente con install-blesh.
- Pausa de shell durante la copia de plugins, con intento de reinicio incluso
  si falla la transacción. Aborda la recarga parcial observada en el portátil;
  no demuestra que todos los fallos posibles de Quickshell estén resueltos.
- Nuevo protocolo AGENTS.md, status de solo lectura, procedencia por transacción
  e informes locales privados. apply sin diferencias registra una comprobación
  del alcance seleccionado; no crea una copia ficticia de configuración.
- Sin cambios de aspecto, selección automática de fondo ni ajustes de hardware.

## Migración

Leer docs/actualizaciones.md. La instalación de septiembre sin procedencia debe
aparecer como desconocida hasta revisión; no confundir git pull con apply.
Conservar componentes existentes. Las dependencias habituales siguen en README;
no se requiere instalar nada nuevo para status/report (Python y Git ya usados).

## Recuperación

Guardar la copia de la aplicación que cambió archivos y usar restore ID. Un verify
vacío no permite deshacer instalaciones anteriores. Los registros v2 siguen legibles.
No borrar manifiestos ni informes para «corregir» una versión desconocida.

## Validación y límites

Probado con 49 tests automatizados en HOME temporal: aplicación, restauración,
procedencia, legado, divergencias, alcance parcial e informe privado. Búsqueda de
emojis y sintaxis de scripts comprobadas. No se ha aplicado esta edición al
escritorio activo ni se ha validado todavía en el portátil; esa comprobación
queda en el informe de su próxima actualización.
Los hashes de archivos mezclados pueden señalar cambios locales legítimos.
La validación visual y el éxito de reinicios no se deducen de status.
