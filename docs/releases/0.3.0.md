# Lavanda 0.3.0 — atajos, editores y Transmission

Fecha: 2026-10-08. Etiqueta: lavanda-v0.3.0.

## Cambios acumulativos desde 0.2.0

Componentes nuevos, de selección explícita (el alcance por defecto no cambia):

- `shortcuts`: Super+Shift+W abre WhatsApp, Super+Shift+C abre VS Code,
  Super+Shift+S captura pantalla como Impr Pant. Sustituyen Omawrite, HEY y Maps.
  Super es la tecla Windows, no Ctrl.
- `editors`: Nano en Bash, sudoedit y Git; función `n` para Nano. VS Code como
  editor de Omarchy y para texto/código. Conserva navegador, PDF y asociaciones
  ajenas. Nano NO se presupone instalado; se incluye como dependencia.
- `transmission`: cliente Qt flotante, estilo oscuro Lavanda, lanzador portable,
  asociaciones torrent/magnet e icono de bandeja activado. Arranque normal visible;
  acción de menú separada para iniciar minimizado. No se copian torrents, rutas,
  contraseñas ni sesiones del equipo de origen. No desinstala GTK automáticamente.
- `utilities`: dependencias opcionales GNOME Clocks, age y gvfs-dnssd. No configura
  cuentas WebDAV ni claves de cifrado. gvfs-dnssd es descubrimiento de servicios;
  no sustituye a GVfs ni garantiza por sí solo el funcionamiento de WebDAV.
- `packages` muestra los paquetes asociados a los componentes elegidos;
  `install-packages` instala los ausentes a través de `omarchy pkg add`, solo en
  una terminal interactiva y de forma explícita. doctor/plan/apply no instalan nada.
- Base del reloj de Try Omarchy 4.0.3-7 revisada: única diferencia
  `Date.timeZoneUpdated()` al refrescar. Se acepta su huella además de la anterior.
  El plugin Lavanda no cambia; no se relajan las demás comprobaciones.

## Procedimiento para el portátil

Leer primero docs/actualizaciones.md y docs/actualizar-portatil.md.
Proponer la selección existente más `shortcuts,editors,transmission`; ofrecer
`utilities` de forma separada. Mantener `workspaces` si ya se usaba.
VS Code debe existir (el comando `code`): conservar su variante instalada. Si falta,
revisar la instalación adecuada antes de continuar; no sustituir silenciosamente
VS Code de Microsoft por Code OSS.

Cerrar Transmission por completo antes de aplicar o restaurar su configuración.
El instalador se detiene si detecta Transmission Qt abierto. Tras aplicar,
abrirlo y comprobar aspecto, ventana flotante y permanencia en bandeja al cerrar.
No confundir minimizar con salir: Salir termina las descargas.
Abrir terminal nueva para Nano/Bash. Algunas apps gráficas requieren cerrar sesión
para heredar las variables de environment.d; no cerrar la sesión automáticamente.

## Copia y recuperación

Los nuevos archivos entran en la misma transacción y restore conservador del
instalador. Conservar el ID de copia. Si Transmission cambia settings.json después
no forzar una restauración que detecte esa divergencia; revisar el archivo.
Las dependencias instaladas se quedan en el equipo al restaurar archivos; no se
eliminan paquetes automáticamente. No se exportan perfiles, .ssh ni credenciales.

## Validación y límites

53 pruebas automatizadas pasan: incluye combinación shell+editores y
workspaces+atajos+Transmission, preservación de datos privados y asociaciones,
aplicación repetida sin cambios y restauración exacta en HOME temporal.
Búsqueda española/inglesa de emojis y sintaxis de scripts comprobadas.
Doctor/plan comprobados en el equipo de oficina con todos los componentes.
También se ensayaron aplicación, segunda aplicación sin cambios y restauración
en HOME temporal contra la base real instalada y el dock descargado y verificado.
No se ha aplicado la nueva edición al escritorio de oficina ni al portátil.
La apariencia original se usó en oficina; la instalación portable y el cierre a
bandeja requieren validación visual en el portátil. No se ha ensayado allí aún.
El dock sigue fijado a la misma revisión; no se actualiza a la punta del fork.

## Fuera de esta versión

Ajustes de QEMU, monitores, USB, cuentas SSH/WebDAV, navegadores y credenciales.
Tampoco fija ni degrada Codex, ni cambia IgnorePkg o actualiza Omarchy completo.
