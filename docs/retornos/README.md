# Retornos entre equipos

Aquí se publican únicamente resúmenes revisados y autorizados por Raúl.
Los informes completos viven en ~/.local/state/omarchy-lavanda/reports/ de cada equipo.

Nombre sugerido: FECHA-portatil.md (o FECHA-laboratorio.md).
Contenido mínimo: versión anterior y destino, alcance, resultado técnico,
validación visual realizada/pendiente, incidencias y siguiente paso.
No incluir nombres de usuario, rutas personales, IP, cuentas ni logs completos.
No hay retornos nuevos publicados todavía; el traspaso privado del 26 de septiembre
es contexto histórico, no un certificado del estado actual del portátil.
